Proxima ML

一个开源的 Minecraft 启动器。装版本、装模组、开房间和朋友联机，都在一个窗口里做完。支持 macOS、Windows 和 Linux。

以前叫 PMCL。由 peddlejumper 个人开发，代码全部公开在 GitHub 上。

下载 查看源代码

当前版本 2.12.0

功能

版本和启动

  • 远古 alpha、beta、正式版和快照都能装
  • 模组加载器：Forge、NeoForge、Fabric、Quilt、OptiFine，还有 LiteLoader、Rift 这些老的
  • 按游戏版本挑 Java：1.12.2 及以前用 8，1.17 起用 17，1.20.5 起用 21，26 起用 25。电脑上没有就自动下载
  • 每个版本可以有自己独立的游戏目录
  • 微软账号登录，也可以用离线账号

下载

  • 内置 Modrinth 和 CurseForge 市场，装模组时把依赖一起装上
  • 可以导入 .mrpack 整合包
  • 下载队列能暂停和重试，每个文件下完都会校验哈希
  • 网络被干扰时会换用系统自带的 curl 重新下载

内容管理

  • 模组、整合包、光影包、投影、资源包、数据包、配置文件，各有一页
  • 先点进要管的版本和实例，再增删里面的文件，不会碰到别的实例
  • 离线账号也能换皮肤

存档

  • 世界和截图会把 HMCL、官方启动器目录里的也一起列出来
  • 录屏
  • 时间机器：定时备份世界，玩坏了可以退回去

联机

  • 建一个房间，把房间码发给朋友，对方填进去就能进你的世界
  • 可选 Terracotta（陶瓦联机）、EasyTier、ConnectX，哪个能连上用哪个
  • 不用自己开服务器，也不用设置端口映射

其他

  • 游戏崩溃后会列出可能的原因。配好模型后可以点「AI 修复」
  • 插件（.ppk 格式）和内置终端
  • NBT 编辑器、音乐播放器
  • 主题色可以从壁纸里取；窗口拉得比宽还高时换成竖屏布局
  • 启动时检查更新，安装包要通过 SHA-256 和 Ed25519 签名校验才会安装

系统文件大小
到 GitHub 下载最新版
  • 安装包里自带 Java 运行时，所以有三四百 MB，装完不用另外装 Java。
  • Mac 目前只有 Apple 芯片（M 系列）的安装包，Intel Mac 暂时没有。
  • JAR 版本要电脑上有 Java 21，用 java -jar 文件名.jar 打开。
  • 装好以后有新版本启动器会提示，不用再回这里下载。

常见问题

游戏和设置存在哪？
用户目录下的 .pmcl 文件夹，版本、实例、模组和设置都在里面。
没看到更新提示？
去「设置 → GitHub Release 同步」看一下，仓库应该填 PCML-Z/PCML。
游戏崩了怎么办？
先看崩溃窗口里列出的原因，常见的是模组冲突或者 Java 版本不对。解决不了的话，把启动器日志贴到 Issues 里。
在哪反馈问题？
GitHub Issues。
