01 / Platforms 无界平台

从 Apple Silicon，
到龙芯。

PMCL 原生运行于 Windows、macOS 与 Linux。在 Apple Silicon 上，古老的 Alpha 版本经由 Rosetta 2 调度 x86_64 Java 悉心呵护；在国产架构上，LoongArch64 与 RISC-V 64 拥有专属的运行时与社区原生库。哪里有热爱，哪里就有 PMCL。

  • x86_64 AMD64最广泛的兼容 —— 工作站、台式机与主流笔记本的第一选择。/01
  • ARM64 AArch64Apple Silicon 与树莓派的原生速度，无需任何转译。/02
  • LOONGARCH64龙芯架构 —— 阿里 Dragonwell 运行时自动就位，Java 8 / 17 / 21 开箱即用。/03
  • RISC-V 64面向新兴架构，Temurin 运行时与社区原生库双向奔赴。/04
  • MIPS64EL老而弥坚 —— 龙芯社区 FTP 精心托管，经典硬件再战十年。/05

03 / Plugins 插件生态

以 .ppk 之名。

用 Kotlin 书写主体，用 Java 打理边角。PMCL 的插件系统开放了界面、下载、账号与启动的每一个环节 —— 你的启动器，理应由你定义。

</plugin>

04 / Engine 下载引擎

快，
且可靠。

CurseForge、Modrinth、MultiMC、FTB —— 各家整合包格式照单全收；PMCL 私有的 LSL3 格式更支持 SHA-1 校验与增量更新。每一份文件都经原子写入，每一次更新都经 Ed25519 签名验证。不损坏，不回退，不将就。

  • CurseForge + Modrinth两大生态，一键安装 —— 指纹 API 自动补全元数据。
  • MultiMC + FTB老牌格式平滑迁移，mmc-pack.json 与组件映射悉数保留。
  • LSL3 PrivatePMCL 私有格式 —— SHA-1 校验、增量更新、断点续传。
  • SecurityEd25519 签名校验 · 原子写入 · 文件级锁 —— 拒绝一切损坏。
