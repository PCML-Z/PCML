# PMCL 2.7.1

## 请尽速更新

为遵守适用法律法规，自本版本起 PMCL 在受限地区（当前为中国大陆）**停止提供以下服务**：

- Minecraft 游戏本体下载
- Minecraft 社区客户端下载
- 游戏服务器连接（仅保留 OPanel 服务器管理）

已安装版本仍可正常启动，存档、模组市场、资源包与启动器其余功能均不受影响。

旧版本仍在提供上述受限服务，存在合规风险，请勿继续使用。

## 变更明细

**合规限制**
- 受限地区下载页不再列出版本，改为显示政策提示
- 受限地区服务器页仅保留 OPanel，不再加载与测速收藏服务器
- 社区客户端（下载页「社区客户端」标签）纳入同等下载限制
- 归属地探测改走直连，量取本机真实出口 IP；开启代理或 VPN 不再能绕过限制

**缺陷修复**
- 修复 macOS 上主题、背景等设置无法持久化保存的问题（配置写盘被系统拒绝导致改动只存在于内存）
- 配置写盘失败现在会在状态栏提示，不再静默失败，也不再残留临时文件

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
