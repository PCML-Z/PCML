# PMCL 2.10.3

## 新功能

**ECXP**
- 应用改成和启动器一致的方正列表
- 安装、打开、日志和移除都留在这一页

**安装器**
- 仓库里增加独立的跨平台安装器
- 按当前系统下载最新的 pkg、msi、deb 或 rpm，再交给系统安装

## 稳定性

- 选择关掉启动器并留下游戏时，后来的关闭不会再把游戏杀掉
- 退出前会把还没写完的账号先保存
- 澪模式开着时，退出不再弹出管理员确认

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
这次更新可以稍后再说。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
