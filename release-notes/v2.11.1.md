# PMCL 2.11.1

## 稳定性

- 2.11.0 会提示安装 2.10.4，是因为窗口标题读的是这次构建写入的版本，更新检查却去读另一个没有版本号的 jar，读不到就当成 2.2a
- 标题和更新检查现在用同一份构建版本。读不到版本时不再当成旧版本去更新
- 下载热更新或安装包前会再确认远程版本更高，避免把新安装覆盖成旧包
- 桌面安装包不再带两份核心类。独立命令行仍使用 cli-all.jar

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
这次更新可以稍后再说。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
