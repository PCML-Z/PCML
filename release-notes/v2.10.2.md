# PMCL 2.10.2

## 新功能

**ECXP**
- 缺少 .NET 时在启动器里下载，走下载队列
- 不再打开浏览器去下载运行时

**开发者**
- 用当前登录的 GitHub 账号做 PMCL 开发者认证
- 名下公开仓库带有主题 `pmcl-plugin` 或 `ecxp-app` 即通过
- 已认证的开发者可以在设置里打开 PMCL 终端日志窗口

**界面**
- 标题栏显示 PMCL 版本号。本地编译版会在后面标「(非发行版本)」
- 关于页使用启动器自己的图标，去掉几何海报
- 去掉蓝色播放按钮图标
- 主题效果里可以调节背景毛玻璃虚化，从 0 到 48

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
这次更新可以稍后再说。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
