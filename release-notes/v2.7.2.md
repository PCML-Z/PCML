# PMCL 2.7.2

## 新功能

**内存占用**
- 内容中心新增「内存」页，每秒刷新启动器、正在运行的游戏和系统内存

**联机**
- 「我的房间」会记住创建或加入过的房间，可以一键重连、复制邀请码、重命名或删除

**公告**
- 任务中心顶部增加公告栏，点开后在独立窗口查看。政策说明随启动器内置，不依赖网络

**外观**
- 安装或命令行可以单独设置主题、字体、缩放和语言，不会改动账号、内存和下载设置

**正版下载**
- 受限地区在完成微软正版账户验证后可以下载游戏本体
- 这样得到的版本只能用正版账户启动，不能改用离线账户

## 修复

- 模组市场下载模组及其依赖时走下载队列，可以在下载中心暂停、取消和限速
- 修正部分简体中文
- 更新说明会写入热更新清单，更新提示不再是空白

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
