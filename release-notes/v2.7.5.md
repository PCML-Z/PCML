# PMCL 2.7.5

## 新功能

**调度中心**
- 可以多开桌面
- 智能体按名字打开页面、拨动设置，并可以听写

**游戏目录**
- 游戏目录可以迁到外置磁盘，扫描、备份和插件仍走同一套接口

**Studio**
- 可以新建 ECXP 应用和 PMCL 插件项目
- 能打开自己建的 ECXP 源文件
- ECXP 页按启动器的卡片重排

**好友**
- 添加好友时能发现同一局域网里的其他 PMCL。两边都要是这个版本、已经登录，并且在同一网络

**崩溃诊断**
- 崩溃窗口可以用已接入的模型阅读这次日志
- 诊断由编进启动器的 Rust 引擎完成
- 调整内存、模组和这一局的 Java 只走接口桥

**版本文件**
- 超过 4 MiB 的 version.json 不再停在加载中，会说明文件太大，并可以在外部打开

**启动页**
- 启动页不再显示内存占用

**关于**
- 引用开源项目补上这次诊断引擎的来源：Axolotl Launcher 和 LogShare

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
这次更新可以稍后再说。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
