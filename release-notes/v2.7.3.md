# PMCL 2.7.3

## 新功能

**扩展内核**
- 设置中新增「扩展内核」，可以导入 Java、C# 或 Rust 内核来扩展启动
- 已安装扩展内核时，启动游戏会先弹出选择窗。默认是 HCS X Pro 2，也可以改用已安装的内核
- 命令行使用 `launch <版本> --kernel builtin` 或 `launch <版本> --kernel <id>`。Companion 启动同样要先选定内核
- 内核与 PMCL 权限相同，只安装你信任的包。C# 内核需要本机已安装 dotnet

**内存**
- 启动页右侧直接显示启动器和正在运行的游戏占用的本机物理内存，每秒刷新
- 统计里的性能页也显示这两项，并带有峰值
- 点启动页上的卡片可以打开内容中心的完整内存占用页

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
