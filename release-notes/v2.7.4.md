# PMCL 2.7.4

## 新功能

**ECXP 应用**
- 侧栏新增「ECXP 应用」，可以安装用 .NET 10 或 .NET 11 写的工具
- 点开后在自己的窗口里运行，并可以调用启动器的接口
- 安装前会列出它能做的事，滑到尽头才确认。只安装你信任的来源
- 本机需要装有对应版本的 .NET 运行时

**删除确认**
- 删除实例、存档、模组、资源包、光影、数据包、截图和录像时，要滑到尽头才生效
- 经典界面和 Studio 都是这样

**音乐**
- 播放时底部音乐条铺满内容区，可以上一首、下一首，并调节音量
- 音乐页增加收藏组

**好友**
- 好友群可以分享群二维码。已经是好友的人扫码后加入这个群

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
这次更新可以稍后再说。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
