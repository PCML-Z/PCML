# PMCL 2.7.6

## 新功能

**图标**
- 界面换成一套简洁图标
- 原来的图标可以在「设置 → 主题 → 图标」换回
- macOS 应用图标仍使用原来的

## 修复

**存档和版本**
- 名为 `.zip` 的压缩包不再把整个存档目录换掉
- 版本号不能跳出目录去读账号文件
- 数据包只能改存档目录里真正的世界

**助手**
- 助手不再导入世界或整合包，也不能开关插件
- 房间状态里不再带邀请码和房间码

**崩溃和启动**
- 某个版本单独设了内存时，崩溃后增大内存改的是这个版本
- 用指定 Java 启动时补上正版检查、崩溃日志，以及正常退出后的自动化
- 从实例页启动也能看到兼容选项和 Java 下载进度
- 游戏还在运行时不能再点重新启动
- 诊断不再把用户名打进报错文本

**好友**
- 局域网发现不再被一条短报文截断后面的发现包

## 更新方式

打开 PMCL 会自动检查并提示更新；也可从本页面下载对应平台的安装包覆盖安装。
这次更新可以稍后再说。
未看到提示的，请在「设置 → GitHub Release 同步」中确认同步已启用、仓库填写正确。
